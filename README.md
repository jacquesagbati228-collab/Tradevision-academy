# Tradevision-academy
TradeVision Academy est une plateforme de formation en trading conçue pour aider les débutants et les traders intermédiaires à comprendre les marchés financiers.  Nous proposons des formations en Forex, Gold (XAUUSD), analyse technique, chandeliers japonais, gestion du risque, psychologie du trading et utilisation de MetaTrader 5 (MT5)
